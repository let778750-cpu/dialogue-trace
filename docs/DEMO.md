The screenshots use `scripts/showcase.py`: a synthetic thermal-drift case, two source tasks, one shared research question, one separate measurement workstream and a checkpoint. Tool outputs are illustrative, not actual experimental evidence. No private transcript is included.

截图使用 `scripts/showcase.py` 的合成温漂案例：两个来源任务、一条共享问题研究线、一条独立测量方案研究线和一个断点。工具输出仅为展示数据，不是实际实验依据；不包含私人对话。

## Suggested sequence / 建议镜头

1. Show the main timeline: user prompt → AI plan → new user constraint → revision.
   展示主时间线：提问 → 方案 → 补充约束 → 修正。
2. Move to the second task, keeping the same research line.
   切到第二段来源任务，保持同一研究线。
3. Open the checkpoint and follow its source link.
   打开研究断点，查看已知、未知、下一步及原话。
4. Open technical records; inspect tool input, result and source. Return to the timeline.
   按需展开工具输入、结果和来源，再返回原阅读位置。
5. Briefly show narrow layout and research-line management.
   简短展示窄屏布局与研究线管理。

Record the app window only, with no personal paths, credentials, private notes or unrelated windows visible. Keep “synthetic example” visible in the project name. Do not describe the prerecorded demo as live host hook verification.

只录制应用窗口，避免个人路径、凭据、真实笔记与其他窗口；保留项目名中的“合成案例”。不要把预先生成的演示称为真实宿主 hooks 验收。
